# 为什么圈X 开着还会刷出广告？

## 结论（先看这个）

红果滑滑流里的广告大致分两类：

| 类型 | 常见表现 | 圈X 能否去掉 |
|------|----------|--------------|
| A. SDK / 素材广告 | 开屏、弹窗、外链下载、独立广告域名请求 | **可以**（重写 + 分流） |
| B. 滑滑流插播广告 | 刷几集后出现，底部有「上滑继续观看短剧」，倒计时后上滑 | **基本不能** |

你现在「刷着刷着还有广告」，多半是 **B 类**。  
它和正片走同一套业务/播放通道（`fqnovel` 系）。之前对这类域名 MitM/改包，就会出现「网络错误，请点击重试」，所以安全版**故意不碰**业务域。

社区里 Android 多用无障碍自动上滑跳过；**iOS 没有同等能力**，圈X 也做不到自动上滑。

---

## 圈X 这边请确认已生效

1. **重写**「红果短剧-去广告」已更新并启用  
2. **分流**「红果短剧-广告域名」已引用，且 **策略 = reject**（只开重写不够）  
3. MitM 已开、证书已信任  
4. MitM 主机名里**没有** `*.fqnovel.com`  
5. 划掉 App 重开（必要时清缓存）

分流地址：

```text
https://raw.githubusercontent.com/zhouyinyuangit/Quantumult-X/main/HongGuo/filter/HongGuo_Ads.list
```

## iOS 上还能怎么减广告（有效）

### 1. App 内关闭广告推送

**我的 → 设置 → 关于红果 → 了解与管理广告推送**

- 关「程序化广告展示」  
- 关「个性化广告展示」  

### 2. 基本功能模式（广告最少，功能会受限）

路径大致为：

**我的 → 设置 → 关于红果 → 隐私政策… → 基本功能模式**

开启后通常会退出登录；看剧广告会少很多，但评论/任务等可能不可用。

### 3. 听剧模式

播放页开「听剧」，部分视频层贴片/弹窗会失效（画面可能黑屏，只听声音）。

### 4. 系统权限

- 关掉红果的「运动与健身 / 加速度计」（减少摇一摇跳转）  
- 关掉通知（减少推送弹窗）

---

## 若要继续用网络规则迭代

请在圈X 打开 **HTTPS 解密 / 记录**，等广告出现时看请求列表，把**明显广告域名**发过来（不要发登录 Cookie）。

可补的：独立广告域名。  
不要补：对整个 `*.fqnovel.com` / 播放 CDN 改包。

---

## 和需求文档的关系

需求文档要求「全程无贴片」。在 iOS + 仅 Quantumult X、且不能破坏播放的前提下，**B 类滑滑流插播无法保证 100%**。  
当前仓库目标调整为：

- 尽量拦 A 类（SDK/素材/追踪）  
- 保证能刷视频  
- 对 B 类给出 App 内减广告方案，并如实说明限制
